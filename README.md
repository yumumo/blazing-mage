# 烈焰法师

横版火系魔法师跑酷小游戏（XRK-AGT Core `www/demo` 静态页）：一边往前冲，一边跳跃、翻滚、发射火球，躲开障碍、打倒怪物、收集金币。

首次进入会有短教程，跟着提示练一遍操作即可。

## 在线游玩

在线地址：[https://blazing-mage.pages.dev/](https://blazing-mage.pages.dev/)

## 怎么玩

1. 打开游戏页，主菜单点 **开始游戏**。
2. 尽可能跑得更远：撞障碍会掉血，血量耗尽本局结束。
3. 本局赚到的金币可在菜单里强化属性、买道具，下一局更轻松。

## 操作

### 键盘

| 按键 | 作用 |
|---|---|
| `W` / `↑` | 跳跃（空中可二段跳） |
| `S` / `↓` | 蹲伏 / 翻滚（可穿过横梁等障碍） |
| `J` | 发射火球（消耗能量） |
| `1`–`4` | 使用对应栏位的道具 |
| `空格` / `回车` | 开始或重开 |
| `F` | 全屏 |
| `M` | 静音 |
| `Esc` | 返回主菜单 |

### 手机 / 触屏

- 上滑：跳跃  
- 下滑：翻滚  
- 屏幕按钮：跳跃、翻滚、攻击  

建议横屏游玩。

## 核心机制

- **能量**：发射火球会消耗能量，能量会自动回复。
- **护盾（永久属性）**：破碎时触发 **天空冲刺**，短时间极速飞过前方危险区。
- **道具护盾**：只挡一次伤害，**不会**触发天空冲刺。
- **金币**：跑步距离、击杀、拾取都能赚；分数随距离、击杀、拾取上涨。
- **传送门**：进入奖励空间后主要捡金币和增益，没有普通障碍。

## 养成与商店

| 属性 | 效果 |
|---|---|
| 生命值 | 上限 3，受击或掉落扣血 |
| 火球速度 | 火球更快 |
| 护盾 | 最多 1 层；破碎触发天空冲刺 |
| 回能速度 | 能量恢复更快 |

| 道具 | 效果 |
|---|---|
| 磁铁 | 一段时间吸引附近金币 |
| 护盾 | 1 层临时护盾 |
| 双倍金币 | 本局拾取翻倍 |
| 复活币 | 死亡后原地复活一次 |

局内也会刷出磁铁、双倍、攻击强化、起飞等临时道具。

## 与 XRK-AGT

本仓库对应 AGT Core 静态应用目录约定：

```text
www/demo/index.html   →  挂载为 /demo
```

在已加载对应 Core 的 AGT 实例上，浏览器访问 `/demo` 即可游玩。本仓库亦可单独用 Cloudflare Pages 发布同一入口。

## Cloudflare Pages

仓库已含 `wrangler.toml`，构建产物目录为 `www/demo`（无构建步骤）。

- 控制台：Workers & Pages → Create → Connect to Git → 选本仓库  
- Framework preset：**None**  
- Build command：留空  
- Build output directory：`www/demo`  

或本机（已登录 `wrangler`）：

```powershell
npx wrangler pages deploy www/demo --project-name=blazing-mage
```

开发数值与机制说明见 [`docs/dev.md`](docs/dev.md)。
