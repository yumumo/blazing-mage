# 古堡跑酷

月夜城墙上的横版跑酷。沿着外墙石道一路向前，跳跃、翻滚、开火，躲开亡灵与机关，收集金币强化角色——冲得越远，城墙上的危机越密。

**在线游玩**：[https://castle-parkour.pages.dev/](https://castle-parkour.pages.dev/)

## 设定

古堡并不只是封闭甬道。你奔跑在**城墙外侧的石道**上：脚下是砖缝与火光，身侧是夜空与垛口。石像苏醒、蝙蝠掠过、地刺与横梁交替逼近；偶尔会出现金色传送门，把你带进短暂的**奖励空间**——那里几乎只有金币与增益，没有杀机。

## 角色

| 角色 | 定位 | 特点 |
|------|------|------|
| **法师**（默认） | 远程 | 法杖火球；可升级生命、火球、护盾、回能 |
| **战士**（金币解锁） | 近战 | 挥剑斩击；更高生命与护盾；天赋「骑士庇护」可在挡伤后短暂起飞 |

主菜单进入 **角色** 页可切换出战、购买战士，并升级属性与天赋。

## 操作

| 输入 | 作用 |
|------|------|
| `W` / `↑` / 上滑 | 跳跃（可二段跳） |
| `S` / `↓` / 下滑 | 翻滚 |
| `J` | 攻击 |
| `1`–`4` | 使用已装备道具 |
| 空格 / 回车 | 开始 / 重开 |
| `Esc` | 返回主菜单 |
| `F` | 全屏 |
| `M` | 静音 |

## 目标

活得更久、跑得更远。距离、击杀与拾取金币都会转化为强化资源；护盾与起飞能在致命危机里争一口气。挑战自己的最远距离与最高分。

## 技术说明

本仓库为可独立发布的静态页游戏（Cloudflare Pages 产物为 `www/castle-parkour/`）。目录分区：`index.html` 壳 + `css/` + `js/`（`config/` 为角色/世界扩展点）+ `assets/`。若嵌在 XRK-AGT 中，挂载路径为 `/castle-parkour`。
