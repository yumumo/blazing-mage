# 烈焰法师 · 开发文档

`www/demo/index.html` 是单文件网页游戏，HTML/CSS/JS 全内联。游戏不依赖外部图片，角色、怪物、金币、道具、背景和 UI 均由 Canvas 或 CSS 过程化绘制；未引用的 `assets/` 贴图目录已删除。

## 发布结构

发布到 GitHub / Cloudflare Pages 时只需要：

```text
index.html
README.md
.gitignore
```

如果从 Core 目录发布，游戏入口是 `core/demo-Core/www/demo/index.html`；如果使用独立仓库，保持 `index.html` 位于仓库根目录即可。

## 核心数值

| 量 | 当前值 | 说明 |
|---|---:|---|
| 画布 | 800 × 500 | 横版网页游戏，适配手机横屏 |
| 地面线 | `GROUND = 480` | 角色脚底与平台判定基准 |
| 基准单位 | `U = 40` | 角色、怪物、障碍尺寸基础 |
| 距离换算 | `PX_PER_METER = 26` | 260px/s ≈ 10m/s |
| 基础速度 | `260 * speedMul()` | 随距离分段提升 |
| 天空冲刺 | 3 秒，最高 2800px/s | 护盾触发，带淡入淡出 |
| 火球 | 半径 7，基础速度 700px/s | 火球升级继续提高速度 |
| 能量 | 100 上限，25/发，30/s 回复 | 默认可 4 连射 |
| 同屏火球 | 6 | 防止无限堆积 |
| 坑宽 | 前期 80-120px，后期 130-180px | 结合冷却与安全区生成 |

## 机制与规则

- 世界位移 `worldX` 是距离、金币和分数的统一真源。
- 分数公式为 `scoreVal() = scoreM()*10 + killCount*50 + coinPickups*20`。
- 本局金币由距离收入、击杀收入、拾取收入共同构成：`goldEarned()`。
- 跳跃支持二段跳；蹲伏触发翻滚；攻击消耗能量并受冷却限制。
- 护盾破碎触发天空冲刺；局内道具护盾只抵挡伤害，不触发天空冲刺。
- 奖励空间通过传送门进入，只生成金币和增益道具，不生成普通障碍。

## 世界生成

- 障碍、坑洞、平台、金币和局内道具都通过世界坐标生成。
- `isRangeFree(cx, cw, pad)` 是实体间距检查的统一入口，避免障碍、平台、金币、道具互相重叠。
- `tryPlace(make, start, end, w)` 负责在安全范围内尝试放置实体，找不到安全位置则跳过。
- 跳跃类障碍共享 `jumpObsCd`，防止墙、怪、地刺、高台连续堆叠。
- 坑洞前后保留安全区，天空冲刺和起飞道具落地时会清除前方障碍。

## 移动端适配

- `viewport-fit=cover` 支持刘海屏安全区。
- 画布按容器等比缩放，手机竖屏可玩，横屏体验更好。
- 700px 以下压缩菜单、HUD、触控按钮和面板间距，避免横向溢出。
- 低高度横屏下隐藏键盘提示，给画布和触控按钮留出空间。
- Canvas 手势支持上滑跳跃、下滑蹲伏；屏幕按钮支持跳跃、翻滚、攻击。

## 操作

| 输入 | 功能 |
|---|---|
| `W` / `↑` / 触屏上滑 / 跳跃按钮 | 跳跃、二段跳 |
| `S` / `↓` / 触屏下滑 / 翻滚按钮 | 蹲伏、翻滚 |
| `J` / 攻击按钮 | 发射火球 |
| `1-4` | 装备或使用道具 |
| 空格 / 回车 | 开始或重开 |
| `F` | 全屏 |
| `M` | 静音 |
| `P` | 性能监控 |
| `Esc` | 返回主页 |

## 测试方法

游戏暴露两个全局钩子，方便 Playwright 或浏览器控制台验证：

- `window.advanceTime(ms)`：模拟时间推进，逐帧调用更新与绘制。
- `window.render_game_to_text()`：返回 JSON 状态快照，包含玩家、障碍、分数、金币、道具等信息。

发布前至少检查：

- 根目录存在 `index.html`。
- 搜索不到 `assets/`、`.png`、`new Image` 等图片依赖。
- 桌面端可进入游戏，触控按钮可触发跳跃和攻击。
- 手机窄屏没有横向滚动，横屏下画布和按钮都可见。
